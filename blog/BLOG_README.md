# Retired upstream blog source

This directory contains inherited Munder Difflin blog source and generated-site tooling. It is kept in the source checkout for attribution and historical reference only; it is not part of OFFICE-X, is not built or published by this fork, and must not be deployed as OFFICE-X content.

OFFICE-X public project information belongs in `docs/`. The old generated `docs/blog/` site and its publish check have been removed so the fork cannot present upstream marketing pages as OQVIAN content.
