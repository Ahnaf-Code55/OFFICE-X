# OFFICE-X project site design

`index.html` is a small, static project overview for OFFICE-X. It uses the OFFICE-X application mark in the site header and displays the OQVIAN company logo separately in the footer. Do not substitute one mark for the other.

## Visual rules

- Use the OFFICE-X dark navy and electric blue/cyan accents for structure and the inherited warm pixel-office palette for product surfaces.
- Keep product and company marks distinct and use the provided SVG/JPEG assets from `brand-assets/`.
- Keep the page responsive, keyboard accessible, and usable with reduced-motion preferences.
- The page is self-contained and must not load analytics, scripts, fonts, images, or video from upstream domains.
- Describe only implemented behavior. Managed-relay availability depends on an OQVIAN deployment; do not imply that this source repository includes a live service.

The full application design system remains documented in [`../DESIGN.md`](../DESIGN.md). The old upstream marketing blog and gallery are not published by OFFICE-X.
